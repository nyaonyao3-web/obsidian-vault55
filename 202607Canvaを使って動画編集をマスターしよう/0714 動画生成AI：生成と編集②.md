###manusでプレミアプロの動画をカット編集するプロンプト###


「アップロードされた動画を解析して、premiere Proで読み込むXMLとしてとして出力してください。

##目的
・アップロードされた「未編集の動画素材」を解析
・VAD (Voice Activity Detection）をもちいて無音区間を検出
・無音部分をカットした編集状態を、premiere Proで即座に読みコミ・再編集できるファイルとして出力する

##重要条件
・**カット後の動画ファイルは書き出さない**（レンダリング・再エンコード不要）
・出力は**「編集用XMLファイルのみ」**
・premiere Proでエラーなく読み込める形式を厳守すること

##処理手順
1. 動画ファイルから音声トラックを解析
2. VADを用いて「発話がある区間」を検出
3. 以下の編集ルールで区間を整形

###編集ルール（テンポ最適化）
*　無音と判定する最小長：0.20秒以上
*　発話区間の前に**0.06秒**、後ろに**0.10秒**のパディングを付与
*　発話区間同士の感覚が**0.15秒未満**の場合は同一クリップとして納める
*　**0.12秒未満**の極端に短い発話区間はノイズとして除外
*　語頭・語尾の欠落を避けつつ、不要な間は極力除去する

##XML仕様（最重要：premiere Pro互換性）

1. **DOCTYPE宣言**:

 * `<media>`>`<video>`>`<samplecharacteristics>` （解析度情報）

(サンプリングレート および ） これらはソース動画の情報を正確に取得し、一致させてください。

### 時間計算とタイムライン構築ルール（最重要）

VADで検出された時間は「秒」ですが、XMLはすべて「フレーム数」で記述する必要があります。以下のルールで計算してください。

1. フレーム変換: 時間（秒）× FPS ＝ フレーム数（小数点以下は四捨五入） 例：30fpsで1.5秒の場合 = 45フレーム
    
2. クリップのIN/OUTとSTART/ENDの厳格な管理: Premiere Proのタイムライン上でクリップを隙間なく並べるため、各において以下の整合性を必ず保ってください。 ・ : 元動画におけるカット開始フレーム ・ : 元動画におけるカット終了フレーム ・ : タイムライン上での配置開始フレーム（1つ前のクリップの の値と完全に一致させること。最初のクリップは0） ・ : + ( - )
    
3. ビデオとオーディオのリンク（同期）: カットした動画と音声がタイムライン上でバラバラにならないよう、同じカット区間のビデオのとオーディオのには、同じ タググループを設定してください。（を使用して互いのIDを結びつけること）
